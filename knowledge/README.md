# 独立课程知识库

base.json 是带版本的独立知识数据；base.js 是用于 file:// 直接加载的相同数据快照。内置 20 条原创教学整理，来源指向官方文档及公开项目，不能等同于教师或规范机构审核。

本地检索采用中文单字、相邻片段与英文词的加权匹配，没有向量服务，也不依赖外部大模型。每次命中返回原条目和出处。用户导入资料不影响计算内核。

用户导入 JSON 示例：

```json
{"cards":[{"title":"本课程提交要求","content":"由课程教师提供的章节与格式要求。","source":"https://example.edu/course"}]}
```

source 可省略，此时标为本地用户资料。链接仅接受 HTTPS，页面不会自动访问。每次最多导入 100 条，单条正文最多 12000 字。用户条目状态固定为待核验。

扩展课程时同时准备：任务书参数定义、明确计算范围、公式或工具来源、独立测试用例、报告模板、检查规则。不要只扩大知识条目数量而不验证计算模块。
